# Food Court Folkestone

A modern, responsive demo website concept for Food Court, 113 Sandgate Rd, Folkestone CT20 2BL.

## Included
- Restaurant-focused landing page
- Menu highlights
- Google review social proof
- Dine-in, takeaway and delivery messaging
- Click-to-call actions
- Google Maps directions
- Responsive mobile navigation
- Mobile-first responsive layout

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Note
The food photography currently uses remote Unsplash image URLs for the demo. Replace these with the client's own photography before production launch.
